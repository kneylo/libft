# ** Libft **
## ** Description **
This project is the first of my cursus at 42 Lausanne, the goal is to create our own C library by recreate standard libc functions,
all the functions got ft_ in front of their initial name and they're all coded following [42 Norme](https://github.com/42School/norminette/blob/master/pdf/en.norm.pdf).
The subject got 3 mandatory parts.
	* basic libc functions
	* additionals functions that are either not included or exist in a different form
	* linked lists
for more information, refer to the subject of the libf that can be found on the intra.

## ** Instructions **
If you want to use this libft you'll need to start by cloning the repo and compile everything

``` shell
$> git clone https://github.com/kneylo/libft.git
$> cd libft
$> make
```

add the .h to your code
``` c
#include "libft.h"
```

and add some compilations flags
``` c
-lft -L path/to/libft.a -I path/to/libft.h
```
